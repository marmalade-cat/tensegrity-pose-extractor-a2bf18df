TensegrityPoseExtractor Prototype

Interactive single-file prototype to digitize 2D plot traces and export normalized CSV/JSON time-series. Load an image, click to add points along a trace, adjust points, then export. Includes a tiny Python loading snippet.

Usage: open index.html in a browser. No dependencies.

Notes: This is a demonstrator for figure digitization; adapting to video or multi-module traces is straightforward by repeating traces or extending exported JSON.
